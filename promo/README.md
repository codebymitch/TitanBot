# فيديوهات CHAOS الإعلانية

3 فيديوهات طولية (1080×1920، 9:16) جاهزة لـ TikTok وInstagram Reels وYouTube Shorts، بالعامية المصرية،
ومعاها موسيقى متعملة من الصفر (مفيش مشاكل حقوق نشر).

| الفيديو | المدة | الفكرة |
|---|---|---|
| `out/v1-main.mp4` | 23.5 ث | الإعلان الرئيسي: "زهقت من السيرفرات الميتة؟" ← اللوجو ← الألعاب ← الـ CC ← البورصة ← اللفلات ← ادخل |
| `out/v2-bourse.mp4` | 22 ث | البورصة: "ممكن تبقى غني من ديسكورد؟" ← لوحة الأسعار ← صفقة بمكسب +267 CC ← خلي بالك ← الأوامر |
| `out/v3-invite.mp4` | 20 ث | الانفايتات: "صاحبك يساوي 1000 CC" ← الخطوات ← رتب الانفايت ← 10 صحاب = 10,000 CC |

جنب كل فيديو صورة غلاف (`out/*-cover.png`).

كل الأرقام من إعدادات البوت الحقيقية: 1000 CC لكل انفايت يوصل لفل 5 ويكمل 3 أيام
(`src/config/inviteRewards.js`)، `10 × اللفل` CC مع كل لفل، أصول البورصة وحد الـ 10% في الساعة وضريبة البيع 1.5%
(`src/config/store/bourse.js`).

## النشر

آخر مشهد بيقول **"اللينك في البايو 👇"**، فحط لينك السيرفر في البايو بتاعك. عايز اللينك نفسه يظهر في الفيديو؟

```bash
node render.mjs --invite discord.gg/XXXX
```

### كابشن مقترح

- **v1**: زهقت من السيرفرات الميتة؟ 💀 تعالى CHAOS 🔥 ألعاب، عملة خاصة، بورصة ولفلات… والفوضى شغالة 24 ساعة. اللينك في البايو 👇
- **v2**: ممكن تبقى غني من ديسكورد؟ 🤑 في CHAOS فيه بورصة أسعارها بتتغير كل ساعة… اشتري رخيص وبيع غالي 📈
- **v3**: صاحبك يساوي 1000 CC 😳 ابعتله انفايت، يوصل لفل 5، وخد الـ CC. هات صحابك وتعالى 🔥

**هاشتاجات**: `#ديسكورد #discord #سيرفر_ديسكورد #discordserver #مصر #جيمنج #gaming #fyp #explore #CHAOS`

### نصايح

- انشر في وقت الذروة (8–11 بالليل بتوقيت مصر) وثبّت أحسن فيديو في البروفايل.
- ابدأ بـ v1، وبعده بيومين v2 ثم v3، وبعد كده كرر بكابشنات مختلفة.
- اطلب من الأعضاء يعملوا duet / stitch أو يشاركوه في الستوري؛ وممكن تعمل مسابقة CC لأكتر حد جاب مشاهدات.
- ضيف صوت ترند من التطبيق نفسه بصوت واطي فوق الموسيقى لو عايز وصول أكبر.

## التعديل وإعادة الرندر

كل فيديو صفحة HTML (`v1-main.html`، `v2-bourse.html`، `v3-invite.html`) تقدر تفتحها في المتصفح وتتفرج عليها
مباشرة. النصوص في الصفحة نفسها؛ كل مشهد `section.scene` ليه `data-start` و`data-end` (بالثواني)،
وكل عنصر فيه `data-at` = بعد قد إيه من بداية المشهد يظهر.

```bash
cd promo
npm install playwright            # أو اعمل link لنسخة موجودة
pip install numpy scipy imageio-ffmpeg
node render.mjs                   # كل الفيديوهات
node render.mjs v2-bourse         # فيديو واحد
node render.mjs --preview         # نسخة سريعة للمراجعة (12 فريم/ث، من غير صوت)
```

- `shared.css` / `shared.js`: الشكل المشترك ومحرك التايم لاين (كل أنيميشن بيتوقف ويتنقل لوقت الفريم بالظبط).
- `music.py`: بيعمل الموسيقى (120 BPM) ويحط whoosh قبل كل قطع وضربة (impact) في الأوقات اللي في `body[data-hits]`.
- `render.mjs`: بيصور كل فريم بـ Playwright ويبعته لـ ffmpeg (H.264 + AAC).
- الخطوط (Anton، Cairo، Lalezar) في `fonts/` برخصة SIL OFL.
