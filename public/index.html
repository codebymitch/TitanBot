מלאו בקשה קצרה ומאובטחת. לאחר ההגשה הבוט ישלח לכם הודעת אימות פרטית.

  • 🔒 הבקשה אינה מתפרסמת בפומבי
  • ✅ אימות זהות דרך הודעה פרטית מהבוט
  • 🛡️ רק צוות EditIL יכול לצפות בבקשה
בקשת הצטרפות לצוותכל השדות המסומנים נדרשים
לא יודעים איך למצוא את ה־User ID? הצגת מדריך＋
💻 במחשב
  1. פתחו את Discord ולחצו על גלגל השיניים ליד השם שלכם.
  2. עברו אל Advanced והפעילו Developer Mode.
  3. לחצו לחיצה ימנית על המשתמש שלכם.
  4. בחרו Copy User ID והדביקו אותו בשדה.
📱 בטלפון
  1. פתחו הגדרות משתמש ב־Discord.
  2. עברו אל Advanced והפעילו Developer Mode.
  3. פתחו את הפרופיל שלכם ולחצו על תפריט שלוש הנקודות.
  4. בחרו Copy User ID והדביקו אותו בשדה.

ה־User ID הוא מספר באורך 17–20 ספרות. אל תשלחו סיסמה או טוקן.

למי הקהילה מתאימה?＋

לעורכים מתחילים ומקצועיים, יוטיוברים, עורכי גיימינג, יוצרי TikTok ומעצבי תנועה.

ההצטרפות בחינם?＋

כן. אפשר להצטרף לקהילה, לשתף, ללמוד ולהכיר עורכים ללא תשלום.

איך מוצאים עורך או צוות?＋

בשרת קיימים ערוצים ייעודיים לחיפוש עורכים, צוותים, פרויקטים ושיתופי פעולה.

מה מקבלים בוסטרים?＋

גישה לאזור בוסטרים עם לאונג׳, פריסטים, משאבים בלעדיים ומתנות קהילה.
