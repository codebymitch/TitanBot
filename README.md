# TitanBot - Ultimate Discord Bot

TitanBot provides Discord server management and community features including moderation, tickets, applications, leveling, giveaways, birthdays, utility tools, verification, welcome messages, and reaction roles.

## Commands

Use `/help` in Discord to browse currently enabled commands. Administrators can use `/commands dashboard` to manage command availability for their server.
