# היום שלי — קלוריות · הרגלים · תזכורות

אפליקציית ווב קטנה (עובדת גם בטלפון) עם תפריט ראשי שמוביל לשלושה מסכים:

- **🔥 קלוריות ותזונה** — יומן לפי ארוחות עם ערכים תזונתיים מלאים (קלוריות, חלבון, פחמימות, שומן, סיבים, סוכר, נתרן), מאגר של 166 מאכלים + מאכלים אישיים, מועדפים ואחרונים, העתקה מאתמול, סטטיסטיקה שבועית, מעקב משקל ו־BMI, ומחשבון יעד (BMR/TDEE) עם חלוקת אבות מזון. לחיצה על עיגול הקלוריות פותחת את הגדרות הקלוריות (יעד יומי, אבות מזון ומחשבון).
- **✅ הרגלים** — הרגלי סימון או כמות (עם יעד ויחידה), תזמון: כל יום / ימים מסוימים / X בשבוע, תזכורת יומית, אייקון וצבע, רצף ושיא, אחוז הצלחה, לוח חודשי לעריכת ימים קודמים, הערות, עריכה, סידור, ארכיון ומחיקה.
- **💧 שתיית מים** — מעקב כוסות מול יעד יומי, גרף שבועי ותזכורת לשתות כל X דקות בטווח שעות.
- **⏰ תזכורות** — הוספה מהירה או מפורטת, הערות, חזרות (יומי, ימי חול, ימים בשבוע, חודשי, שנתי, כל X שעות/ימים/שבועות, תאריך סיום), התראה מוקדמת, עדיפות, רשימות, נודניק, חיפוש, היסטוריה, שכפול, ותזכורת במייל דרך Google Calendar / Outlook.

תפריט ☰ (למעלה משמאל) → **חשבון**: כשהאפליקציה נפתחת מ־claude.ai עם משתמש מחובר, הנתונים נשמרים בחשבון של כל משתמש בנפרד ומסונכרנים בין מכשירים. בלי חיבור — הכל נשמר מקומית בדפדפן (localStorage).

## הרצה

```bash
cd daily-app
python3 -m http.server 8080
# ואז לפתוח http://localhost:8080
```

אפשר גם לפתוח את `index.html` ישירות בדפדפן (בלי התראות ו־offline).
בטלפון: "הוספה למסך הבית" כדי להשתמש בה כמו אפליקציה.

> התזכורות קופצות כשהאפליקציה פתוחה או ברקע בדפדפן; אין שרת push, כך שאחרי סגירה מלאה ההתראה תופיע בפתיחה הבאה.
