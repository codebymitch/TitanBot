# היום שלי — קלוריות · הרגלים · מים · תזכורות

אתר בעברית (מותאם לטלפון) למעקב יומי:

- **🔥 קלוריות ותזונה** — יומן לפי ארוחות עם ערכים תזונתיים מלאים (קלוריות, חלבון, פחמימות, שומן, סיבים, סוכר, נתרן), מאגר של 166 מאכלים + מאכלים אישיים, מועדפים ואחרונים, העתקה מאתמול, סטטיסטיקה שבועית, מעקב משקל ו־BMI. לחיצה על עיגול הקלוריות פותחת את ההגדרות (יעד יומי, אבות מזון ומחשבון BMR/TDEE).
- **✅ הרגלים** — הרגלי סימון או כמות, תזמון (כל יום / ימים מסוימים / X בשבוע), תזכורת יומית, אייקון וצבע, רצף ושיא, אחוז הצלחה, לוח חודשי לעריכת ימים קודמים, עריכה, סידור, ארכיון.
- **💧 שתיית מים** — כוסות מול יעד, גרף שבועי, תזכורת לשתות כל X דקות בטווח שעות.
- **📅 לוח שנה** — מאגד את כל התזכורות (כולל חזרות והיסטוריה) בתצוגת חודש, שבוע, יום (לפי שעות) ורשימה; תאריך עברי, חגים וימי זיכרון, סינון לפי רשימות, שכבות הרגלים ותזונה, הוספה ועריכה ישירות מהלוח.
- **📋 משימות** — רשימות נפרדות בהתאמה אישית (שם, אייקון, צבע), רשימות חכמות (היום / מתוכננות / הכל), תאריך ושעת יעד, עדיפות, הערות, תתי־משימות, שכפול, העברה בין רשימות, ומחיקת רשימה עם העברת המשימות. משימות עם תאריך מופיעות בלוח השנה.
- **⏰ תזכורות** — חזרות גמישות, התראה מוקדמת, עדיפות, רשימות, נודניק, חיפוש, שכפול, ותזכורת במייל דרך Google Calendar / Outlook.
- **👤 חשבון** (תפריט ☰) — הרשמה והתחברות במייל וסיסמה או עם Google; הנתונים נשמרים בענן ומסונכרנים בין מכשירים. בלי חשבון — הכל נשמר בדפדפן.

האתר הוא קבצים סטטיים בלבד (HTML/CSS/JS), בלי שלב build.

## הרצה מקומית

```bash
cd daily-app
python3 -m http.server 8080
# http://localhost:8080
```

## העלאה לאוויר (GitHub Pages, בחינם)

1. למזג את הקוד ל־`main`.
2. ב־GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. אם ה־repo הוא fork: בלשונית **Actions** ללחוץ על "I understand my workflows, go ahead and enable them".
4. ה־workflow ‏`.github/workflows/deploy-daily-app.yml` מעלה את האתר אוטומטית בכל עדכון של `daily-app/` ב־`main` (או ידנית: Actions → Deploy daily-app website → Run workflow).
5. האתר יהיה בכתובת: `https://<שם-המשתמש>.github.io/<שם-ה־repo>/` — כאן: **https://ofeknave.github.io/KayDee/**

## חשבונות משתמשים (Firebase, בחינם)

בלי השלב הזה האתר עובד במצב מקומי. כדי להפעיל הרשמה, התחברות וסנכרון:

1. נכנסים ל־<https://console.firebase.google.com> → **Add project** (אפשר לכבות Google Analytics).
2. **Build → Authentication → Get started → Sign-in method**: מפעילים **Email/Password**, ואם רוצים גם **Google**.
3. **Build → Firestore Database → Create database** (Production mode, מיקום קרוב, למשל `europe-west`).
   בלשונית **Rules** מדביקים את התוכן של `daily-app/firestore.rules` ולוחצים **Publish** — כך כל משתמש רואה רק את הנתונים שלו.
4. **Project settings (⚙️) → General → Your apps → Web (`</>`)** → נותנים שם → מעתיקים את אובייקט `firebaseConfig`.
5. מדביקים אותו בקובץ `daily-app/firebase-config.js` במקום `null`:
   ```js
   window.FIREBASE_CONFIG = { apiKey: "...", authDomain: "...", projectId: "...", storageBucket: "...", messagingSenderId: "...", appId: "..." };
   ```
   (הערכים האלה לא סודיים — האבטחה היא בכללי Firestore.)
6. **Authentication → Settings → Authorized domains** → מוסיפים את `ofeknave.github.io` (ו־`localhost` כבר קיים לבדיקות).
7. עושים commit ל־`main` — האתר יתעדכן תוך דקה-שתיים.

### איך הנתונים נשמרים
- כל משתמש מקבל מסמך אחד: `users/{uid}` עם כל הנתונים שלו.
- בהרשמה ראשונה, מה שכבר נשמר בדפדפן עובר לחשבון החדש.
- אחרי התנתקות, הנתונים נשארים בחשבון ומופיעים שוב בהתחברות מכל מכשיר.
