# היום שלי — קלוריות · הרגלים · תזכורות

אפליקציית ווב קטנה (עובדת גם בטלפון) עם תפריט ראשי שמוביל לשלושה מסכים:

- **🔥 קלוריות** — יעד יומי, הוספת מאכלים לפי ארוחה, כפתורי הוספה מהירה, טבעת התקדמות ומעבר בין ימים.
- **✅ הרגלים** — יצירת הרגלים עם אימוג׳י, סימון יומי, רצף ימים (streak) ותצוגת 7 הימים האחרונים.
- **💧 שתיית מים** — מעקב כוסות מול יעד יומי, גרף שבועי ותזכורת לשתות כל X דקות בטווח שעות.
- **⏰ תזכורות** — תזכורת עם תאריך ושעה, חזרה יומית/שבועית, התראות דפדפן, סימון כבוצע וניקוי.

תפריט ☰ (למעלה משמאל) → **חשבון**: כשהאפליקציה נפתחת מ־claude.ai עם משתמש מחובר, הנתונים נשמרים בחשבון של כל משתמש בנפרד ומסונכרנים בין מכשירים. בלי חיבור — הכל נשמר מקומית בדפדפן (localStorage).

## הרצה

```bash
cd daily-app
python3 -m http.server 8080
# ואז לפתוח http://localhost:8080
```

אפשר גם לפתוח את `index.html` ישירות בדפדפן (בלי התראות ו־offline).
בטלפון: "הוספה למסך הבית" כדי להשתמש בה כמו אפליקציה.

> התזכורות קופצות כשהאפליקציה פתוחה או ברקע בדפדפן; אין שרת push, כך שאחרי סגירה מלאה ההתראה תופיע בפתיחה הבאה.
